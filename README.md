# Personal Portfolio
Static site (HTML/CSS/vanilla JS). No build step or backend.

1. Replace every `[PLACEHOLDER]` in `index.html` and in the content block at the top of `script.js`.
2. Add images: `assets/images/profile.jpg`, `assets/projects/*.png`.
3. For each project set `projectUrl` / `githubUrl`; set `embed: true` for a live iframe preview (the host must allow framing). Buttons with empty URLs are hidden.
4. Deploy: push to GitHub, then import into Vercel/Netlify, or enable GitHub Pages. No secrets belong in this repo.
